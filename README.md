# Mova — Sitio web

Landing page de **Mova**, la app de gestión de gimnasios (Flutter + Firebase).

Sitio estático (HTML/CSS/JS, sin build). Muestra las funciones de la app, capturas y enlaces de descarga.

## Estructura

```
index.html    → página
styles.css    → estilos
script.js     → interacciones (nav, animaciones)
assets/       → logo y capturas
```

## Descargas

Los instaladores (Android / Windows) se publican como **Releases** de este repositorio y el botón de descarga apunta a ellos.

## Desarrollo local

Abrí `index.html` en el navegador, o serví la carpeta:

```bash
npx serve .
```
